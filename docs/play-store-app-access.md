# Google Play "앱 액세스 권한(App access)" 심사용 안내 — 인생의 회전목마

> 콘솔 경로: **앱 콘텐츠 → 앱 액세스 권한**
> 로그인이 **카카오/구글 OAuth 전용**이라 심사자가 들어갈 수 있게 계정 + 로그인 절차를 제공해야 함. (안 하면 "심사자가 앱에 접근 불가"로 반려)

## 콘솔 설정
1. 앱 콘텐츠 → 앱 액세스 권한 → **"전체 또는 일부 기능에 액세스 제한됨"** 선택
2. **"새 안내 추가"** 클릭 → 아래 입력
   - **이름**: 전체 앱 로그인
   - **사용자 인증 정보(아이디/비번)**: 심사용 **구글 계정** 이메일 + 비밀번호
     - ⚠️ 본인이 구글 계정 하나를 새로 만들거나 기존 부계정을 심사 전용으로 제공 (계정 생성은 직접 하셔야 함)
   - **추가 안내**: 아래 KO/EN 문구 붙여넣기

---

## 심사자 안내 문구 (한국어)
```
이 앱은 카카오 또는 구글 계정 로그인이 필요합니다.

[로그인 방법]
1. 앱 첫 화면에서 "구글로 시작하기" 버튼을 누르세요.
2. 제공된 구글 계정(아이디/비밀번호)으로 로그인하세요.
3. 최초 로그인 시 생년월일·성별 등 간단한 온보딩을 완료하면 메인 화면(오늘의 운세)으로 진입합니다.
   - 이미 온보딩이 완료된 계정을 제공했다면 바로 메인 화면이 보입니다.

모든 핵심 기능(운세, 사주, 타로, 멤버 대화)은 로그인 후 이용 가능합니다.
앱 내 결제 UI는 정책에 따라 Android 앱에서는 표시되지 않습니다.
```

## Reviewer instructions (English)
```
This app requires sign-in with a Kakao or Google account.

[How to sign in]
1. On the first screen, tap "Start with Google" (구글로 시작하기).
2. Sign in with the provided Google account (email/password below).
3. On first sign-in, complete a short onboarding (birth date, gender), then you reach the main screen (Today's Fortune).
   - If the provided account is already onboarded, the main screen appears directly.

All core features (fortune, saju, tarot, member chat) are available after sign-in.
Note: in-app purchase UI is intentionally hidden on the Android app per store policy.
```
