# 7일 운세 리포트 기획안

작성일: 2026-06-01

## 한 줄 설명

최근 7일 동안 사용자가 본 운세·감정 기록·출석 변화를 묶어서 "이번 주 내 기운이 어떻게 움직였는지" 보여주는 라이트 전용 리포트.

## 왜 필요한가

오늘 운세는 하루짜리라 금방 지나간다. 7일 리포트는 사용자가 "내 기운이 쌓이고 있다"는 느낌을 받게 해서 재방문 이유를 만든다.

## 첫 버전 범위

첫 버전은 새 DB 표 없이 만든다. 이미 있는 데이터만 사용한다.

- `daily_fortunes`: 최근 7일 운세 점수와 카테고리
- `mood_entries`: 최근 7일 감정 기록
- `streaks`: 연속 방문일
- `profiles`: 사주·성격유형 기반 개인화

새 결제 상품이나 가격 변경은 하지 않는다. KCP 심사 동결 영역인 `/pricing`, `/login`, 사업자 정보, 약관·개인정보·환불 페이지도 건드리지 않는다.

## 사용자 여정

1. 사용자가 `/today`에 들어온다.
2. 최근 7일 중 기록이 3일 이상이면 "7일 기운 보기" 카드가 보인다.
3. 누르면 리포트 화면 또는 모달이 열린다.
4. 기록이 부족하면 "3일만 더 보면 기운이 열려요"처럼 자연스럽게 재방문을 유도한다.

## 화면 구성

- 이번 주 한 줄 총평
- 7일 점수 변화 그래프
- 가장 좋았던 날 / 조심할 날
- 감정 패턴 요약
- 반복해서 나타난 운세 키워드 3개
- 다음 7일 조언
- 어울리는 캐릭터 추천

## 문구 톤

숫자 분석처럼 차갑게 말하지 않는다. "이번 주엔 물러서는 날보다 다시 붙잡는 날이 많았어"처럼 캐릭터가 살아서 읽어주는 느낌을 유지한다.

## 멤버십 제안

- 무료 사용자: 기운 카드 미리보기까지만 노출
- 라이트 이상: 전체 7일 리포트 열람
- 프로: 캐릭터별 한마디 또는 다음 7일 행동 처방 추가

가격표 문구는 PG 심사 중이므로 지금은 바꾸지 않는다. 멤버십 권한만 기존 구독 상태로 판단한다.

## 개발 단계

1. 데이터 읽기 함수 만들기: 최근 7일 운세·감정·출석을 한 번에 가져온다.
2. 리포트 생성 함수 만들기: 기록이 부족하면 생성하지 않는다.
3. `/today` 카드 추가: 기존 화면 구성을 깨지 않게 작게 시작한다.
4. 라이트 권한 체크: 기존 구독 확인 함수 재사용.
5. QA: 기록 0일, 2일, 3일, 7일, 라이트/무료 계정 각각 확인.

## 나중에 확장할 것

- 7일 리포트 저장용 `weekly_fortune_reports` 표 추가
- 매주 일요일 자동 생성 알림
- 이미지 카드 다운로드
- 친구 공유용 요약 링크

확장은 PG·앱 심사 이후에 진행한다.
